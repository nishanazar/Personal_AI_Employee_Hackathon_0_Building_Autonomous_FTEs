# AI Employee Vault

An intelligent file monitoring and task management system that uses AI to automate workflow processes in an Obsidian-style vault.

## Overview

The AI Employee Vault is designed to monitor file changes in a designated vault directory and automatically create action items when new files are detected. This system implements an automated workflow with three main folders:
- **Inbox**: Files placed here trigger automatic processing
- **Needs_Action**: Contains action items generated by the system
- **Done**: Completed tasks are moved here

## Features

- **File System Monitoring**: Continuously monitors the Inbox folder for new files
- **Automatic Action Creation**: Generates Markdown action files when new items are detected
- **Intelligent Processing**: Creates structured action items with file previews and metadata
- **Extensible Architecture**: Built with an abstract base class for easy extension
- **AI Integration**: Designed to work with AI assistants like Claude Code

```
├── Inbox/                   # Monitored folder for new files
├── Needs_Action/            # Generated action items
├── Done/                    # Completed tasks
├── Company_Handbook.md      # Rules and guidelines
├── Dashboard.md             # Status dashboard
└── README.md               # This file
```

## How It Works

1. Place files in the `Inbox` folder to trigger processing
2. The `FileSystemWatcher` detects new files every 30 seconds
3. For each new file, an action item is created in the `Needs_Action` folder
4. Action items contain file metadata, content preview, and processing instructions
5. Completed tasks are moved to the `Done` folder

## Usage

### Starting the Watcher

```bash
python start_watcher.py
```

The watcher will continuously monitor the Inbox folder and create action items as needed.

### Testing AI Integration

Run the test script to verify AI integration:

```bash
python claude_integration_test.py
```

## Configuration

The system can be configured by modifying the parameters in `start_watcher.py`:
- `watch_folder`: Folder to monitor (default: "Inbox")
- `check_interval`: Time between checks in seconds (default: 30)
